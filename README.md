Iqra University Website

A simple university website project developed using HTML and CSS. The website provides information about the university, its courses, faculty, results, admissions, and other student-related services.

About the Project

The Iqra University Website is a static front-end website designed to provide students and visitors with important university information in an organized and easy-to-use way.

The project contains separate pages for different university services, including courses, faculty, results, admission cards, contact information, feedback, login, and signup.

How to Run

This is a static website, so no server or database is required.

Download or clone the repository.
Open the project folder.
Make sure the media folder stays in the same location.
Open index.html in a web browser.

The website will run directly in the browser.
